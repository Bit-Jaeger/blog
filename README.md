# Blog
This Repo is a personal webpage to explore and webdevelopment and tipping my toes into handling static web pages
**Live Demo** [View the website here](https://blog.jaegerlab.link/)

# Description
At first this page was pure HTML, CSS and I wanted to study some basic principles. 
Later I converted over to use Jekyll to actively make use of hosting at GitHub Pages and making the blog part of it more maintainable for me.

# Features
- Responsive design
- Randomly generated quotes (to getting used to retrieving data via .json format)
- Changing theme
- creating new blogposts via markdown (using Jekyll)

# Tech Used
- HTML5 - Structure
- CSS3 - Custom Styling
- JavaScript - Displaying quotes, changing theme
- GitHub Pages - Deployment and hosting
- Jekyll - static site generator

# Future Plans
- This page should ultimately be a part of my own [Domain](jaegerlab.link) webdev "sandbox".

# Local Setup
If you want to setup the page or fork it - feel free to do so! If you are familiar with how jekyll works, then the creation of new blogs should be no problem at all. 
`git clone https://github.com/Bit-Jaeger/blog.git`
